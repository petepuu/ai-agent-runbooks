# HR Onboarding Agent (GHCP)

## Scenario Overview

| Attribute | Value |
|---|---|
| Scenario type | Employee self-service (HR) |
| Platform | Microsoft Copilot Studio - GitHub Copilot harness |
| Primary components | Instructions, ServiceNow knowledge, reusable Agent Skills, connector tools |
| Complexity | Intermediate; production email automation requires additional controls |
| Status | Implementation guide; target-tenant validation required |
| Documentation reviewed | September 15, 2026 |

Build an HR onboarding assistant using the GitHub Copilot harness in Microsoft Copilot Studio. The agent answers questions from approved ServiceNow knowledge, creates source-linked onboarding checklists, and prepares email replies through a controlled workflow.

**GHCP here means the harness inside Copilot Studio**, not GitHub Copilot coding agent, a GitHub Actions workflow, or a repository configured with Copilot instructions. Keeping these files in GitHub does not deploy an agent or install its skills.

## Problem and Outcomes

New hires need reliable answers about onboarding, company policies, benefits, and where to get help. The agent reduces repetitive HR inquiries by retrieving approved policy information, citing its sources, and turning documented onboarding steps into a useful checklist.

The intended outcomes remain faster onboarding, more consistent guidance, and lower HR support workload. Grounding and skills help improve consistency; neither guarantees factual accuracy or eliminates hallucinations.

## Skills Included

| Skill | When it should activate | Result |
|---|---|---|
| [hr-policy-answer](./0.Resources/Skills/hr-policy-answer/SKILL.md) | A direct question about a documented HR policy, benefits, leave, payroll process, or onboarding guidance | Supported answer, source links, missing information, and next step |
| [hr-onboarding-checklist](./0.Resources/Skills/hr-onboarding-checklist/SKILL.md) | A first-day/first-week checklist or onboarding plan request | Checklist separating policy requirements from explicitly labeled suggestions |
| [hr-email-triage](./0.Resources/Skills/hr-email-triage/SKILL.md) | A request to draft an HR email response, or an authorized email-event task | Grounded reply proposal or escalation; never an autonomous send by the skill |

The runtime uses skill descriptions to decide which instructions to load. These are not exact trigger phrases or a guaranteed sequential pipeline. The email and checklist skills contain their own grounding requirements, so they do not depend on another skill being invoked first.

## In Scope / Out of Scope

### In Scope

- Read-only answers to onboarding, HR policy, benefits, and payroll-process questions, grounded in approved ServiceNow knowledge with source citations.
- First-day and first-week onboarding checklists based on documented requirements; checklist generation does not track or complete tasks.
- Three reusable Agent Skills for policy answers, onboarding checklists, and HR email reply drafting.
- Email-triggered draft preparation through a GHCP workflow that invokes the published agent, with an HR review or escalation path.
- Deployment to Microsoft Teams and Microsoft 365 Copilot with authenticated access and source-permission validation.

### Optional Extensions Within Scope

- Cited onboarding document generation, when the native file capability is available.
- Controlled email replies through the separate workflow, only after recipient authorization, recipient-safe knowledge scope, approval rules, and duplicate-send controls are implemented and validated. The baseline remains draft-only; importing a skill does not enable sending.

### Out of Scope

- Access to personal employee records, medical details, or individual HR case data.
- Live employee-data lookups, including leave balances, individual pay, benefit eligibility, or current organization charts.
- Transactional HR workflows such as payroll processing, personal-data updates, leave submission, or benefit enrollment.
- Account provisioning, training completion, or recording policy acknowledgments and checklist completion.
- Case management or ticket creation, including ServiceNow Incident creation.
- Unrestricted autonomous email sending, forwarding, or reply-all; direct publishing to the unavailable GHCP Email channel.
- Custom model training or fine-tuning, and company-policy answers based on public web content or unsupported model knowledge.

### Safety Defaults

Interactive access uses the authenticated user's access boundary. Autonomous work uses its configured connection identity, not automatically the email sender's identity. Persistent memory is off for this baseline.
